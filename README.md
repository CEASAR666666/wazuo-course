# 小瓦作·大智慧

瓦作文化课程网站，包含学生端和教师端。根据保留网页及历史修改记录恢复至 2026-08-12 中英双语视频版本。

[在线访问](https://ceasar666666.github.io/wazuo-course/)

## 内容

- 学生端：教学视频入口、63 条纹样、制瓦工坊、拓片、手绘及线稿涂彩工具。
- 中英文课程切换，7 组小测试，每组 8 道题。
- 教师端：6 个主题教案、432 种课件组合路径、学生测评查看及 CSV 导出。
- 测评结果保存在当前设备和浏览器的 localStorage 中，不跨设备同步。

## 当前资源状态

本次发布不包含视频、图片和 PPT。相关位置留空，视频播放和 PPT 下载需待资源补入后使用。依赖图片的纹样、拓片和线稿预览也暂时留白。

`resource-paths.json` 列出页面使用的资源路径。可将素材放入相应目录后重新发布。

## 本地打开

直接用浏览器打开 `index.html` 即可查看网页。需要本地预览服务时，安装 Python 3 后运行 `Start_Mac.command` 或 `Start_Windows.bat`。

这是静态 HTML/CSS/JavaScript 网站，无需安装前端依赖或构建。GitHub Pages 从 `main` 分支根目录发布。
