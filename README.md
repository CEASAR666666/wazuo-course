# 小瓦韵·大课堂

瓦当非遗通识互动课堂 —— 一套面向中小学的瓦当文化数字课程，纯静态网页，开箱即用。

**[在线访问](https://ceasar666666.github.io/wazuo-course/)**

> 一枚瓦当，是屋檐的护甲，也是古人写给天地的祝福。

## 这是什么

瓦当是中国古建筑屋檐最前端的构件，既保护椽头、引导雨水，也用云纹、莲花、兽面、吉语把古人的祝福刻在屋檐上。本项目把这一非物质文化遗产做成可看、可点、可动手的数字课堂，分学生端与教师端。

## 功能

### 学生端

| 模块 | 内容 |
| --- | --- |
| 教学视频 | 8 讲瓦当微课，带中文字幕，本地播放 |
| 随堂小测 | 每讲 8 题，共 64 题，按视频内容命制，提交后本机留存成绩与解析 |
| 纹样库 | 63 枚瓦当纹样，分 11 类；每枚附所属朝代、纹样特征、文化寓意、历史小故事 |
| 制瓦工坊 | 选土 → 制坯 → 刻纹 → 入窑四步模拟，泥料与轮缘厚度可调，成品可存图 |
| 瓦当拓片 | 按住拖动模拟扑墨，墨色分层叠加显出纹样 |
| 纹样手绘 | 八方界格底稿描摹，支持撤销与笔锋调节 |
| 纹样涂彩 | 8 张矢量线稿**分区上色**：点一下整块填色，另有 6 套传统配色一键套用 |
| 同学作品 | 15 件课堂实拍作品展示 |

### 教师端

| 模块 | 内容 |
| --- | --- |
| 生成教案 / PPT | 6 年级 × 3 课时 × 6 主题 × 4 风格的组合路径，输出教学设计与课件 |
| 研学方案设计 | 依托**陕西境内**瓦当资源点位，生成线路、日程、任务单、安全须知与评价表 |
| 学情诊断报告 | 读取本机测评记录，逐题统计正确率、判定重难点并给出复习建议 |
| 学生作品点评 | 按作品类型分维度评分，输出亮点、改进建议与教师评语 |
| 测评结果 | 成绩汇总、统计看板、CSV 导出 |

四项生成结果均可导出为标准 **.docx**（页面内置最小 ZIP + OOXML 生成器，无外部依赖）。

## 技术说明

- **纯静态**：HTML / CSS / JavaScript 全部内嵌在 `index.html`，无需 npm 安装、无需构建、不依赖任何前端框架或 CDN。
- **完全离线**：视频、图片、课件均从本地目录读取，不联网、不上传。
- **数据只在本机**：测评记录与学生作品存于浏览器 `localStorage`（键名 `wazuoVideoQuizResults`、`wazuoStudentWorks`），不跨设备同步。
- **矢量线稿**：涂彩用的 8 张瓦当线稿由程序按极坐标生成，每个可上色区域都是独立 SVG path，因而支持点击分区填色并可无损导出。
- **docx 导出**：自实现 CRC32 + store 模式 ZIP 打包，输出符合 OOXML 规范的 7 部件文档包，Word / Pages / WPS 均可直接打开。

## 本地运行

推荐用附带的脚本启动本地服务：

```bash
# macOS
./Start_Mac.command
```

Windows 双击 `Start_Windows.bat`（二者均需 Python 3）。

也可以手动起一个静态服务：

```bash
python3 -m http.server 8731
```

然后访问 <http://127.0.0.1:8731/index.html>。

> **不建议直接双击 `index.html`。** 以 `file://` 协议打开时，视频可以播放，但「保存作品」「下载 docx」等功能会被浏览器的本地文件安全策略拦截。
